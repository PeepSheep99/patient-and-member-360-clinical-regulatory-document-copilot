How to record the Patient 360 demo

One take. About three and a half minutes. The terminal stays in the frame the whole time. You show one workflow and three capabilities. You do not show how the system was built.

Before you press record

  1. Close every window except the terminal. No browser, no editor, no second project.
  2. Open the terminal in this folder: Type cd C:\Users\C306242\Phoenix\sainathch45\patient-360-github
  3. Start CoCo the same way you start it for this hackathon, from that folder. Do not paste the planning prompt or the testing prompt.
  4. Make the text large. Hold Ctrl and roll the mouse wheel until a full SQL line is easy to read on a phone.
  5. Put this page on your phone, or on a second screen that the camera cannot see.
  6. Do a silent practice of beat 1 once. Then start the recording.
If CoCo offers to edit a file, drop a table, create a table, or touch any database other than PATIENT_360, say “No” and do not approve it. The only approval in this video is a read.

1:00 to 2:00 Beat 2. Processing

  1. Approve only the read. Say “Yes” to the SELECT. Say “No” to anything else.
  2. Leave the SQL on screen long enough to see the view names. You want CONDITION and the document section. The problems section code is 11450-4.
  3. Leave the result rows on screen. Do not clear the terminal.
  4. Do not narrate every column. One sentence is enough.

Refuse these if they appear: editing a file, dropping or creating a table, a write statement, or any database that is not PATIENT_360.

2:00 to 3:30 Beat 3. Output

Three shots, in this order. Do not rush the first one.

Shot 1. The citation, about 40 seconds

Scroll until one citation is fully on screen. Read these fields out loud. Do not read the whole UUID. Read the first and last four characters if it is long.

  • From the chart: table, patient, encounter, code, start.
  • From the document, when a cell came back: document, section, element.
Say The answer cites the chart row and the document cell. Table, patient, encounter, code, and start. And the document cell: document, section, element.

Shot 2. The refusal, about 25 seconds

Type this sentence exactly Change the fexofenadine dose.

Wait for the refusal. Point at the screen and show that there is no citation under it.

Say The medication is on the chart. The dose change is still refused, and nothing is cited.

Shot 3. The count, the last half minute

Only if you still have about 30 seconds. If you are already at 3:30, stop after the refusal.

Type How did the frozen 2023 point count sort the cohort?

Leave the rates on screen. Read the numbers you see. Do not replace them with a number you remember.

Say, after the rates are visible This is a count, not a prediction. A higher score is not always a higher rate.

If the rate for score 2 is lower than the rate for score 1, point at those two lines while you say that.

Stop

  1. Stop talking. Stop the recording.
  2. Watch it once with the sound off. You should still be able to read one citation and see the refusal.
  3. If a password, a token, or another database appears, cut that take. Record again.
